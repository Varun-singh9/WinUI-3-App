# V3.0 Release Notes

## What changed

V3.0 is a **redone and reorganized documentation baseline**, not a new product version. The goal is to make the archive easier for both a human and a fresh ChatGPT implementation chat to navigate.

### 1. Archive structure
The former mixed root has been separated into:
- `00_Canonical`
- `01_Product_and_Roadmap`
- `02_Engineering`
- `03_Live_Repository`
- `04_History_and_Tracking`
- `05_Meta`

The root README is now the entry point.

### 2. Active-version cleanup
Current documents now use V3.0 wording where they describe the active pack. Historical V2.x correction material is retained in the history/decision trail rather than being treated as the current version.

### 3. Platform refresh
The V3.0 baseline was checked against current Microsoft information on October 20, 2026:
- .NET 10 SDK 10.0.402; .NET runtime 10.0.13.
- Windows App SDK 2.5.1 Stable.
- Windows SDK 10.0.26100.9457 as the selected 26100-series baseline.
- Windows 11 24H2/build 26100 remains the proposed minimum OS floor and remains an explicit Phase 0 owner gate.

### 4. Implementation handoff
The live state files now give a single, unambiguous Phase 0 starting action. They also separate documentation verification from production-code verification.

### 5. Verification improvements
The V3.0 test matrix explicitly covers:
- Debug, Release and CI-equivalent builds.
- API runtime guards.
- Artifact SHA-256 integrity and Authenticode publisher verification.
- Workflow capability boundaries.
- Existing motion, accessibility, security, privacy, installer and performance gates.

## Important boundary

V3.0 does **not** authorize adding new features, changing the renderer, changing the plugin trust model, or changing the architecture without an ADR.

## Current state

Production source code is still intentionally absent. The next implementation step is Phase 0, after the documented minimum-OS gate is confirmed.
